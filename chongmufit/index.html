주요 기능

💰

회비 청구·입금 관리

회원별 잔액을 자동으로 계산해요. 누가 냈고 누가 안 냈는지 한눈에.

완납부분납미납과납
📥

모임통장 엑셀 가져오기

은행 거래내역 파일을 그대로 가져와 입금을 회원과 맞춰요. 암호가 걸린 파일도 열립니다.

🧾

지출 관리와 모임 잔액

지출을 카테고리로 기록하면 모임 잔액(회계)이 자동으로 정리돼요.

📊

리포트·납부 현황 공유

연간 리포트와 납부 현황을 만들어 단톡방에 이미지·텍스트로 공유하세요.

🔒

광고도 추적도 없음

모든 데이터는 서버 없이 기기 안에만 저장됩니다. 회원가입도 없어요.

💾

백업 · 복원

백업 파일을 내보내 두면 기기를 바꿔도 그대로 이어 쓸 수 있어요.

자주 묻는 질문

회비는 어떻게 청구하나요?

거래 → 회비 청구에서 회원을 여러 명 선택하고 적요·금액·청구일을 넣으면 한 번에 등록됩니다. 정기·일시 구분 없이 모두 같은 "청구 건"이고 적요로 구분하므로, 회원마다 금액이 다르면 청구 건을 따로 만들어 주세요.

입금자명이 회원 이름과 다릅니다.

가져온 입금 내역은 총무가 직접 회원과 맞춰 확정합니다. 회사명이나 가족 이름으로 들어온 입금도 원하는 회원에게 배정할 수 있어요. 매칭을 확정하기 전까지는 회원이 배정되지 않은 상태로 남습니다.

은행 거래내역은 어떻게 가져오나요?

거래 → 거래내역 가져오기에서 은행에서 내려받은 파일을 선택하면 됩니다. 암호가 걸린 파일은 앱에서 암호를 입력해 바로 열 수 있고, 미리보기에서 가져올 항목을 고른 뒤 확정합니다.

모임을 여러 개 관리할 수 있나요?

네. 대시보드 맨 위의 모임 이름을 탭하면 모임을 전환하거나 새로 추가할 수 있습니다. 모임 이름과 아바타도 거기서 바꿉니다. 회원·청구·입금·지출은 모임별로 따로 관리됩니다.

납부 현황을 회원들에게 어떻게 알리나요?

리포트 화면에서 만들어 카카오톡 등으로 공유하세요. 실명 마스킹을 켜면 이름 없이 요약만 담긴 단톡방용 리포트가, 끄면 총무가 확인할 실명 명단이 만들어집니다.

미납 회원에게 알림이 가나요?

총무핏은 회원에게 알림을 보내지 않습니다. 회원은 앱을 설치할 필요가 없고, 총무가 만든 리포트를 단톡방에 공유하는 방식입니다.

데이터를 백업하거나 새 기기로 옮기려면?

설정 → 백업 내보내기로 파일을 만들고, 새 기기에서 총무핏을 설치한 뒤 가져오기로 그 파일을 선택하면 됩니다. 적요·날짜·아바타까지 그대로 복원됩니다.

내 데이터는 어디에 저장되나요?

총무핏은 모든 데이터를 기기에만 저장하며, 어떠한 데이터도 외부로 전송하지 않습니다. 광고와 추적 기능이 없습니다. 자세한 내용은 개인정보처리방침을 참고해 주세요.
